# Файлы, которые кладутся сюда вручную

Всё из этой папки доступно на сайте по адресу от корня:
файл `public/logo.svg` открывается как `https://qazaq-tas.kz/logo.svg`.

| Файл             | Что это                                           | Требования                                                                                                                                                       |
| ---------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `logo.svg`       | Логотип в шапке сайта                             | SVG (лучше всего) или PNG с прозрачным фоном. Высота в шапке — 36 px, ширина подстраивается. Если файла нет, показывается текстовое написание «QAZAQ TAS GROUP». |
| `logo-white.svg` | Версия логотипа для тёмного фона                  | Понадобится, когда появится тёмная тема или тёмный подвал                                                                                                        |
| `favicon.ico`    | Значок во вкладке браузера                        | 32×32 или 48×48                                                                                                                                                  |
| `og-image.jpg`   | Картинка при отправке ссылки в WhatsApp и соцсети | 1200×630 px                                                                                                                                                      |

## Как добавить логотип

1. Положите файл сюда с именем `logo.svg`.
2. Обновите страницу — логотип появится в шапке автоматически, менять код не нужно.

Если логотип в PNG или JPG, переименуйте его в `logo.svg` не получится — вместо этого
скажите, и в коде поменяем расширение на нужное (`apps/web/src/components/site-header.tsx`).
